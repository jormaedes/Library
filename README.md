# 📚 Library

A simple **Library application** built with **Vanilla JavaScript**, developed as part of **[The Odin Project](https://www.theodinproject.com/)** curriculum.

This project focuses on practicing object-oriented JavaScript, DOM manipulation, and user interaction without using external libraries or frameworks.

---

## 🧠 About the Project

The Library App allows users to add books to a personal library by providing basic information such as title, author, number of pages, and reading status.  
All books are stored in an in-memory array and rendered dynamically on the page.

This project was created to strengthen understanding of:
- JavaScript objects and constructors
- DOM manipulation
- Event handling
- Data-to-DOM synchronization

---

## ✨ Features

- Add new books via a form
- Display all books dynamically on the page
- Toggle book read/unread status
- Remove books from the library
- Each book is uniquely identified to ensure correct DOM updates

> ⚠️ Note: The data is **not persisted**. Reloading the page will reset the library.
